\section*{1. Arquitectura de Defensa en Profundidad (Three-Tier Defense)}
El sistema implementa una arquitectura rigurosa donde los datos atraviesan tres barreras de control antes de persistirse de forma definitiva:

\begin{itemize}[leftmargin=1.5em, itemsep=0.1em]
    \item \textbf{Capa 1: Frontend (Ergonomía y UX):} Valida en tiempo real mediante eventos reactivos, proporcionando feedback visual inmediato (\texttt{is-valid} / \texttt{is-invalid}), máscaras numéricas y telefónicas, y desactivación de botones de acción para prevenir dobles envíos.
    \item \textbf{Capa 2: Backend (Dominio y Verdad Absoluta):} Obligatoria. Emplea \texttt{DataAnnotations} y DTOs fuertemente tipados. El servidor \textbf{no confía} en los totales ni precios calculados por el cliente: recalcula subtotales con datos de BD y verifica la disponibilidad de stock en transacciones aisladas. Respuestas estandarizadas bajo \textbf{RFC 7807 (ProblemDetails)}.
    \item \textbf{Capa 3: Base de Datos (Última Barrera Irrevocable):} Restricciones a nivel de esquema DDL en SQLite: índices únicos compuestos, límites estrictos de longitud (\texttt{VARCHAR}), integridad referencial con \texttt{ON DELETE RESTRICT} y restricciones \texttt{CHECK} (\texttt{Precio > 0}, \texttt{Stock >= 0}, \texttt{Recibido >= Total}).
\end{itemize}

\section*{3. Certificación del Entorno de Pruebas Automatizadas}
Se implementó el proyecto satélite \textbf{\texttt{tests/sistema\_ventas.Tests}} con \textbf{xUnit 2.9} y \textbf{FluentAssertions 7.2}, ejecutando pruebas aisladas con SQLite en memoria (\texttt{DataSource=:memory:}):

\begin{itemize}[leftmargin=1.5em, itemsep=0.1em]
    \item \textbf{Pruebas de Frontera en Base de Datos (\texttt{DatabaseConstraintsTests}):} Verifican que inserciones directas que violen \texttt{CHECK} (precio negativo, stock negativo, cantidad cero o cambio inválido) o \texttt{UNIQUE} (duplicados de categorías, productos o emails) sean irrevocablemente abortadas con \texttt{DbUpdateException}.
    \item \textbf{Pruebas de Modelos y Lógica de Negocio (\texttt{ModelValidationTests}):} Verifican \texttt{DataAnnotations}, rechazo de emails malformados, nombres cortos y exactitud en algoritmos de cálculo de totales y cambio.
    \item \textbf{Resultado de Ejecución:} \textcolor{success}{\textbf{20 de 20 pruebas ejecutadas con éxito (100\% de efectividad)}}.
\end{itemize}
